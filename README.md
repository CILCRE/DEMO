# 影像素材合集 · Visual Assets Gallery

3D 渲染静帧、雕塑材质试验与实拍影像的集中展示页。单文件静态站点，打开即用。

🔗 **在线预览**：https://cilcre.github.io/DEMO/

---

## ✨ 特性

- 📄 **单文件**：仅一个 `index.html`，零依赖、零构建
- 🖼️ **分类过滤**：图片 / 视频 一键切换
- 🔍 **灯箱预览**：大图查看、视频播放、左右切换
- 🎞️ **视频缩略图**：自动取帧，支持"换帧"手动挑选（选择会记住）
- ⌨️ **键盘操作**：`←` `→` 切换 · `Esc` 关闭 · `空格` 播放/暂停
- 📱 **响应式**：移动端自动适配，竖版视频不会裁切

---

## 🚀 使用

下载 `index.html` 与素材放在同一目录，用浏览器直接打开即可。

### 新增素材
编辑文件内的 `ITEMS` 数组，追加一条记录：

```js
// 图片
{ type:"image", src:"your.png", ratio:16/9,
  title:"标题", tag:"标签", desc:"描述" }

// 视频
{ type:"video", src:"your.mp4",
  title:"标题", tag:"视频", desc:"描述",
  thumbAt: 5 }
